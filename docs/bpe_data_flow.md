# BPE 数据流程图

## 1. BPE 训练流程 (train_bpe)

```
┌─────────────────────────────────────────────────────────────────────────────────┐
│                              BPE 训练流程                                         │
└─────────────────────────────────────────────────────────────────────────────────┘

输入文件 (input_path)
    │
    ▼
┌─────────────────────────────────────────────────────────────────────────────────┐
│  步骤 1: 读取语料                                                                 │
│  ─────────────────                                                               │
│  "Hello World! Hello there."                                                     │
│                                                                                  │
│  代码: text = f.read()                                                           │
└─────────────────────────────────────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────────────────────────────────────┐
│  步骤 2: 预分词 (_pretokenize_chunk)                                              │
│  ─────────────────────────────────                                               │
│  使用 GPT-2 正则表达式分割文本，空格附加到下一个词                                    │
│                                                                                  │
│  "Hello World! Hello there."                                                     │
│       │                                                                          │
│       ▼                                                                          │
│  ["Hello", " World", "!", " Hello", " there", "."]                               │
│                                                                                  │
│  代码: regex.finditer(GPT2_SPLIT_PATTERN, text)                                  │
└─────────────────────────────────────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────────────────────────────────────┐
│  步骤 3: UTF-8 编码 + 频率统计                                                     │
│  ──────────────────────────────                                                  │
│  每个预分词结果转换为字节序列，统计频率                                               │
│                                                                                  │
│  "Hello"  → b"Hello"  = (72, 101, 108, 108, 111)  频率: 2                        │
│  " World" → b" World" = (32, 87, 111, 114, 108, 100)  频率: 1                    │
│  "!"      → b"!"      = (33,)  频率: 1                                           │
│  " there" → b" there" = (32, 116, 104, 101, 114, 101)  频率: 1                   │
│  "."      → b"."      = (46,)  频率: 1                                           │
│                                                                                  │
│  代码: token_counts[token.encode("utf-8")] += 1                                  │
└─────────────────────────────────────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────────────────────────────────────┐
│  步骤 4: 初始化词汇表                                                              │
│  ─────────────────────                                                           │
│                                                                                  │
│  vocab = {                                                                       │
│      0: b'\x00',  1: b'\x01',  ...,  255: b'\xff',   ← 256 个单字节               │
│      256: b'<|endoftext|>',  ...                     ← 特殊 tokens (如果有)       │
│  }                                                                               │
│                                                                                  │
│  代码: vocab_bytes = {i: bytes([i]) for i in range(256)}                         │
└─────────────────────────────────────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────────────────────────────────────┐
│  步骤 5: 转换为 token ID 序列                                                      │
│  ─────────────────────────────                                                   │
│                                                                                  │
│  words = {                                                                       │
│      (72, 101, 108, 108, 111): 2,        # "Hello" 出现 2 次                     │
│      (32, 87, 111, 114, 108, 100): 1,    # " World"                              │
│      (33,): 1,                            # "!"                                  │
│      (32, 116, 104, 101, 114, 101): 1,   # " there"                              │
│      (46,): 1,                            # "."                                  │
│  }                                                                               │
│                                                                                  │
│  代码: words[tuple(token_bytes)] = count                                         │
└─────────────────────────────────────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────────────────────────────────────┐
│  步骤 6: 迭代合并 (核心循环)                                                        │
│  ─────────────────────────────                                                   │
│                                                                                  │
│  ┌────────────────────────────────────────────────────────────────────────────┐ │
│  │  迭代 1:                                                                    │ │
│  │  ────────                                                                   │ │
│  │  6a. 统计相邻对频率 (_get_pair_counts):                                      │ │
│  │      (108, 108) → 2  ← "ll" 在 "Hello" 中出现，而 "Hello" 出现 2 次          │ │
│  │      (101, 108) → 2  ← "el"                                                 │ │
│  │      (72, 101)  → 2  ← "He"                                                 │ │
│  │      (111, 32)  → 1  ← "o " (跨词边界，但预分词已处理)                         │ │
│  │      ...                                                                    │ │
│  │                                                                             │ │
│  │  6b. 选择最高频率的对 (平局按字节序):                                          │ │
│  │      best_pair = (108, 108)  # "ll"                                         │ │
│  │                                                                             │ │
│  │  6c. 创建新 token:                                                          │ │
│  │      vocab[256] = b"ll"                                                     │ │
│  │      merges.append((b"l", b"l"))                                            │ │
│  │                                                                             │ │
│  │  6d. 更新所有词 (_merge_word):                                               │ │
│  │      (72, 101, 108, 108, 111) → (72, 101, 256, 111)  # "He" + "ll" + "o"    │ │
│  │                     ↑↑                  ↑                                   │ │
│  │                    合并               新 ID                                  │ │
│  └────────────────────────────────────────────────────────────────────────────┘ │
│                                      │                                           │
│                                      ▼                                           │
│  ┌────────────────────────────────────────────────────────────────────────────┐ │
│  │  迭代 2:                                                                    │ │
│  │  ────────                                                                   │ │
│  │  统计新的对频率...                                                           │ │
│  │  best_pair = (101, 256)  # "e" + "ll" = "ell"                               │ │
│  │  vocab[257] = b"ell"                                                        │ │
│  │  merges.append((b"e", b"ll"))                                               │ │
│  │  更新词...                                                                   │ │
│  └────────────────────────────────────────────────────────────────────────────┘ │
│                                      │                                           │
│                                      ▼                                           │
│                                    ...                                           │
│                          (重复直到达到 vocab_size)                                 │
│                                                                                  │
└─────────────────────────────────────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────────────────────────────────────┐
│  输出                                                                            │
│  ────                                                                            │
│                                                                                  │
│  vocab = {                               merges = [                              │
│      0: b'\x00',                             (b'l', b'l'),      # 第 1 次合并    │
│      1: b'\x01',                             (b'e', b'll'),     # 第 2 次合并    │
│      ...                                     (b'H', b'ell'),    # 第 3 次合并    │
│      255: b'\xff',                           ...                                 │
│      256: b'll',                         ]                                       │
│      257: b'ell',                                                                │
│      258: b'Hell',                                                               │
│      ...                                                                         │
│  }                                                                               │
│                                                                                  │
└─────────────────────────────────────────────────────────────────────────────────┘
```

## 2. BPE 编码流程 (Tokenizer.encode)

```
┌─────────────────────────────────────────────────────────────────────────────────┐
│                              BPE 编码流程                                         │
└─────────────────────────────────────────────────────────────────────────────────┘

输入文本: "Hello World"
    │
    ▼
┌─────────────────────────────────────────────────────────────────────────────────┐
│  步骤 1: 特殊 token 分割 (如果有)                                                  │
│  ────────────────────────────────                                                │
│                                                                                  │
│  输入: "Hello<|endoftext|>World"                                                 │
│        │                                                                         │
│        ▼                                                                         │
│  分割: ["Hello", "<|endoftext|>", "World"]                                       │
│              ↓           ↓            ↓                                          │
│           普通文本    特殊token     普通文本                                        │
│                                                                                  │
│  代码: re.split(f"({self.special_pattern})", text)                               │
└─────────────────────────────────────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────────────────────────────────────┐
│  步骤 2: 预分词 (对非特殊 token 部分)                                               │
│  ────────────────────────────────────                                            │
│                                                                                  │
│  "Hello World"                                                                   │
│       │                                                                          │
│       ▼                                                                          │
│  ["Hello", " World"]                                                             │
│                                                                                  │
│  代码: regex.finditer(GPT2_SPLIT_PATTERN, segment)                               │
└─────────────────────────────────────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────────────────────────────────────┐
│  步骤 3: UTF-8 编码                                                               │
│  ──────────────────                                                              │
│                                                                                  │
│  "Hello"  → b"Hello"  = [72, 101, 108, 108, 111]                                │
│  " World" → b" World" = [32, 87, 111, 114, 108, 100]                            │
│                                                                                  │
│  代码: token.encode("utf-8")                                                     │
└─────────────────────────────────────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────────────────────────────────────┐
│  步骤 4: 应用 BPE 合并 (_apply_bpe) - 核心算法                                      │
│  ──────────────────────────────────────────────                                  │
│                                                                                  │
│  以 "Hello" = [72, 101, 108, 108, 111] 为例:                                     │
│                                                                                  │
│  初始状态 (单字节):                                                               │
│  ┌─────┬─────┬─────┬─────┬─────┐                                                │
│  │  H  │  e  │  l  │  l  │  o  │                                                │
│  │ 72  │ 101 │ 108 │ 108 │ 111 │                                                │
│  └─────┴─────┴─────┴─────┴─────┘                                                │
│                                                                                  │
│  假设 merges = [(b'l', b'l'), (b'e', b'll'), (b'H', b'ell'), (b'Hell', b'o')]   │
│  merge_priority = {(b'l',b'l'):0, (b'e',b'll'):1, (b'H',b'ell'):2, ...}         │
│                                                                                  │
│  ┌────────────────────────────────────────────────────────────────────────────┐ │
│  │  迭代 1:                                                                    │ │
│  │  ────────                                                                   │ │
│  │  扫描所有相邻对，查找在 merge_priority 中优先级最高的:                          │ │
│  │                                                                             │ │
│  │  (H, e)   → 不在 merges 中                                                  │ │
│  │  (e, l)   → 不在 merges 中                                                  │ │
│  │  (l, l)   → 优先级 0 ✓                                                      │ │
│  │  (l, o)   → 不在 merges 中                                                  │ │
│  │                                                                             │ │
│  │  选择 (l, l)，合并为 "ll":                                                   │ │
│  │  ┌─────┬─────┬──────┬─────┐                                                 │ │
│  │  │  H  │  e  │  ll  │  o  │                                                 │ │
│  │  │ 72  │ 101 │ 256  │ 111 │                                                 │ │
│  │  └─────┴─────┴──────┴─────┘                                                 │ │
│  └────────────────────────────────────────────────────────────────────────────┘ │
│                                      │                                           │
│                                      ▼                                           │
│  ┌────────────────────────────────────────────────────────────────────────────┐ │
│  │  迭代 2:                                                                    │ │
│  │  ────────                                                                   │ │
│  │  扫描相邻对:                                                                 │ │
│  │                                                                             │ │
│  │  (H, e)   → 不在 merges 中                                                  │ │
│  │  (e, ll)  → 优先级 1 ✓                                                      │ │
│  │  (ll, o)  → 不在 merges 中                                                  │ │
│  │                                                                             │ │
│  │  选择 (e, ll)，合并为 "ell":                                                 │ │
│  │  ┌─────┬───────┬─────┐                                                      │ │
│  │  │  H  │  ell  │  o  │                                                      │ │
│  │  │ 72  │  257  │ 111 │                                                      │ │
│  │  └─────┴───────┴─────┘                                                      │ │
│  └────────────────────────────────────────────────────────────────────────────┘ │
│                                      │                                           │
│                                      ▼                                           │
│  ┌────────────────────────────────────────────────────────────────────────────┐ │
│  │  迭代 3:                                                                    │ │
│  │  ────────                                                                   │ │
│  │  (H, ell) → 优先级 2 ✓                                                      │ │
│  │  (ell, o) → 不在 merges 中                                                  │ │
│  │                                                                             │ │
│  │  选择 (H, ell)，合并为 "Hell":                                               │ │
│  │  ┌────────┬─────┐                                                           │ │
│  │  │  Hell  │  o  │                                                           │ │
│  │  │  258   │ 111 │                                                           │ │
│  │  └────────┴─────┘                                                           │ │
│  └────────────────────────────────────────────────────────────────────────────┘ │
│                                      │                                           │
│                                      ▼                                           │
│  ┌────────────────────────────────────────────────────────────────────────────┐ │
│  │  迭代 4:                                                                    │ │
│  │  ────────                                                                   │ │
│  │  (Hell, o) → 优先级 3 ✓                                                     │ │
│  │                                                                             │ │
│  │  选择 (Hell, o)，合并为 "Hello":                                             │ │
│  │  ┌─────────┐                                                                │ │
│  │  │  Hello  │                                                                │ │
│  │  │   259   │                                                                │ │
│  │  └─────────┘                                                                │ │
│  └────────────────────────────────────────────────────────────────────────────┘ │
│                                                                                  │
│  最终结果: [259]                                                                  │
│                                                                                  │
└─────────────────────────────────────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────────────────────────────────────┐
│  步骤 5: 拼接所有 token ID                                                        │
│  ─────────────────────────                                                       │
│                                                                                  │
│  "Hello" → [259]                                                                 │
│  " World" → [32, 260]  (假设 "World" 合并为 260)                                  │
│                                                                                  │
│  最终输出: [259, 32, 260]                                                         │
│                                                                                  │
│  代码: token_ids.extend(self._apply_bpe(token))                                  │
└─────────────────────────────────────────────────────────────────────────────────┘
```

## 3. BPE 解码流程 (Tokenizer.decode)

```
┌─────────────────────────────────────────────────────────────────────────────────┐
│                              BPE 解码流程                                         │
└─────────────────────────────────────────────────────────────────────────────────┘

输入: token_ids = [259, 32, 260]
    │
    ▼
┌─────────────────────────────────────────────────────────────────────────────────┐
│  步骤 1: 查表获取 bytes                                                           │
│  ──────────────────────                                                          │
│                                                                                  │
│  vocab = {                                                                       │
│      ...                                                                         │
│      32: b' ',                                                                   │
│      259: b'Hello',                                                              │
│      260: b'World',                                                              │
│      ...                                                                         │
│  }                                                                               │
│                                                                                  │
│  259 → b'Hello'                                                                  │
│  32  → b' '                                                                      │
│  260 → b'World'                                                                  │
│                                                                                  │
│  代码: tokens = [self.vocab[id] for id in ids]                                   │
└─────────────────────────────────────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────────────────────────────────────┐
│  步骤 2: 拼接 bytes                                                               │
│  ──────────────────                                                              │
│                                                                                  │
│  [b'Hello', b' ', b'World']                                                      │
│              │                                                                   │
│              ▼                                                                   │
│  b'Hello World'                                                                  │
│                                                                                  │
│  代码: text_bytes = b"".join(tokens)                                             │
└─────────────────────────────────────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────────────────────────────────────┐
│  步骤 3: UTF-8 解码                                                               │
│  ──────────────────                                                              │
│                                                                                  │
│  b'Hello World'                                                                  │
│        │                                                                         │
│        ▼                                                                         │
│  "Hello World"                                                                   │
│                                                                                  │
│  注意: 使用 errors="replace" 处理无效 UTF-8                                        │
│        无效字节会被替换为 U+FFFD (�)                                               │
│                                                                                  │
│  代码: text_bytes.decode("utf-8", errors="replace")                              │
└─────────────────────────────────────────────────────────────────────────────────┘
    │
    ▼
输出: "Hello World"
```

```
                                     │
                                     ▼

                    │  │ 4. 初始化 256 字节词汇表   │  │

                    └────────────────┬───────────────┘
                                     │
                        ┌────────────┴────────────┐
                        ▼                         ▼

                    └────────────────────────────────┘
                           │                 │

    │      │          │                         │     │           │
    │      ▼          │                         │     ▼           │
    │  预分词         │                         │  查表           │
    │      │          │                         │     │           │
    │      ▼          │                         │     ▼           │

    │      ▼          │                         │     ▼           │
    │  BPE 合并       │                         │  UTF-8 解码     │
    │      │          │                         │     │           │
    │      ▼          │                         │     ▼           │
    │  [259]          │                         │  "Hello"        │
    │                 │                         │                 │
    └─────────────────┘                         └─────────────────┘


┌─────────────────────────────────────────────────────────────────────────────────┐
│  关键数据结构转换                                                                  │
│  ─────────────────                                                               │
│                                                                                  │
│  训练阶段:                                                                        │
│  str → 预分词列表 → bytes 列表 → tuple[int] (token IDs) → 合并后的 tuple[int]     │

│  list[int] → list[bytes] → bytes → str                                          │
│                                                                                  │
└─────────────────────────────────────────────────────────────────────────────────┘
```

## 5. 关键区别：训练 vs 编码时的合并策略

```
┌─────────────────────────────────────────────────────────────────────────────────┐
│                       训练时 vs 编码时的合并策略对比                                │
└─────────────────────────────────────────────────────────────────────────────────┘

训练时 (train_bpe):                      编码时 (_apply_bpe):
━━━━━━━━━━━━━━━━━━━                      ━━━━━━━━━━━━━━━━━━━━━

选择标准: 全局最高频率                    选择标准: 最高优先级 (最后学到的)
          ↓                                        ↓
┌─────────────────────────┐              ┌─────────────────────────┐
│ 统计整个语料的对频率      │              │ 查找 merge_priority     │
│                         │              │                         │
│ pair_counts = {         │              │ merge_priority = {      │
│   (l, l): 1000,  ← 最高  │              │   (l, l): 0,            │
│   (e, l): 800,          │              │   (e, ll): 1,           │
│   (h, e): 500,          │              │   (H, ell): 2,  ← 最高   │
│   ...                   │              │   ...                   │
│ }                       │              │ }                       │
└─────────────────────────┘              └─────────────────────────┘
          ↓                                        ↓
选择 (l, l) 因为频率最高                   选择优先级最高的可用对

为什么不同？
━━━━━━━━━━━
训练时: 我们要学习哪些对应该合并，所以选频率最高的
编码时: 已经学好了合并规则，按学习的顺序应用即可
        (但要选最高优先级，因为后学的合并依赖先学的)
```
